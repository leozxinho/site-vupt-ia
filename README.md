# Vupt IA

Landing page for **Vupt IA**, a studio that builds custom technology projects.

The visitor describes the project in a short guided form and gets a personal reply saying whether it is feasible and how it would be done.

## Features

- Guided project brief: name, project summary, detailed needs, estimated budget and desired deadline.
- Review step before sending.
- Contact by email or WhatsApp.
- Light and dark theme.
- Everything in a single HTML file.

## Stack

Pure **HTML, CSS and JavaScript** in a single `index.html`, plus the logo in PNG and SVG.

## Running locally

Open `index.html` in the browser, or:

```bash
npx serve .
```
